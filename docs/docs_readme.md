# docs — rôle du dossier

Documentation destinée aux personnes qui découvrent ou contribuent à Kwatsur. `architecture.md` explique le parcours des données ; `api.md` décrit les routes disponibles.

## Règles de contribution

- Explique les décisions et le fonctionnement en phrases courtes.
- Distingue les fonctionnalités actives de celles qui restent à configurer.
- Garde les instructions de démarrage cohérentes avec le README racine.

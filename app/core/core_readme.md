# core — rôle du dossier

Configuration de l’application, journalisation et erreurs partagées. `config.py` charge les variables d’environnement ; aucun secret n’est codé en dur.

## Règles de contribution

- Garde les réglages d’intégration côté serveur et documente chaque nouvelle variable.
- N’ajoute pas de logique de recherche dans les fondations.
- Ne journalise pas de clés API ni de coordonnées personnelles.

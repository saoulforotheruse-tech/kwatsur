# js — rôle du dossier

Modules JavaScript de l’interface : `app.js` pilote le formulaire et les requêtes ; `components/` construit les cartes et le tableau de comparaison.

## Règles de contribution

- Utilise `textContent` pour afficher les données retournées par l’API.
- Ne duplique pas les filtres métier dans le navigateur.
- Garde les états de chargement et d’erreur visibles et accessibles.

# assets — rôle du dossier

Images, icônes, avatars et autres ressources visuelles utilisées par les pages du frontend.

## Règles de contribution

- Utilise des noms descriptifs et conserve les crédits ou licences nécessaires.
- Optimise les médias pour le web et n’y ajoute aucun secret.
- Range chaque ressource dans son sous-dossier dédié.
